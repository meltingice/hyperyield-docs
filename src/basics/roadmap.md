# Roadmap

Below is a list of potential future features. It is not an exhaustive list or in any particular order and it may change at any time.

* Allow multiple open positions and the ability to allocate a portion of funds to each.
* Different position and rebalance strategies.
* Include full transaction logs that can be viewed on Hyperyield (you can still view these in your favorite block explorer).
* Notification of rebalances via Telegram.
* Additional yield strategies.
